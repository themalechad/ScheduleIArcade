Schedule I Arcade M2.3 - Vanilla knock / mouse UI fix

Observed in the user's current game:
- Arcade StaticDoor resolves correctly as BuildingName='Arcade'.
- Door path: Map/Hyland Point/Region_Northtown/Arcade (1)/arcade/CornerDoor/Metal Glass Door (Static)
- StaticDoor.SUMMON_DURATION is 8 seconds in the supplied Assembly-CSharp dump.

Changes:
1. The mod now waits the full vanilla 8-second knock/summon window before showing its fallback Enter Arcade UI.
2. If NPCSummonMenu opens during that window, Enter Arcade is injected into the native menu instead of showing a separate prompt.
3. If nobody answers, the fallback prompt explicitly uses Player.Deactivate(true), PlayerCamera.FreeMouse(), CursorLockMode.None, and Cursor.visible=true so the mouse can click it.
4. Cancel/Enter restore normal gameplay input and mouse lock.
5. E/Enter also selects Enter Arcade; Escape cancels as a backup.
6. Three callbacks generated by one knock are debounced so they do not restart the wait timer.
7. The exact Arcade BuildingName is now used; unrelated doors are no longer accepted as a fallback.
8. Harmony hooks now reference the IL2CPP wrapper types directly. This removes AccessTools.TypeByName's UnityEngine assembly scans and the LightProbesQueryDisposeJob reflection warnings seen in the log.
