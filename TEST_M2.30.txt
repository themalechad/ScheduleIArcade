Schedule I Arcade M2.31 - Arcade Ambience IL2CPP Compile Fix

This build preserves M2.29 ambience behavior and fixes the MelonLoader IL2CPP compile error:
CS1674: UnityWebRequest used in a using statement must implement System.IDisposable.

The loader now explicitly calls UnityWebRequest.Dispose() instead of using C# `using`.

Test:
1. Run BUILD_AND_INSTALL.cmd.
2. Confirm ScheduleIArcade.dll compiles and installs.
3. Enter the custom arcade.
4. Confirm arcade_ambience.mp3 fades in and loops.
5. Exit the arcade.
6. Confirm ambience fades out and stops.
7. Re-enter multiple times and confirm only one ambience source plays.

Preferences:
AmbienceEnabled = true
AmbienceVolume = 0.35
AmbienceFadeSeconds = 1.25
