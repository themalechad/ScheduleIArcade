M2.8 REAL FBX RUNTIME ASSET FIX
===============================

Reason:
The procedural test room proved the door/teleport flow but did not give a useful visual interior, and the user's previous screenshot showed the remote world sky instead of a recognizable arcade.

Implementation:
- Converted the supplied binary FBX 7400 scene to a tiny custom runtime mesh package.
- Preserved all seven scene meshes and UVs.
- Applies the supplied diffuse textures, plus normal/emission maps where available.
- Builds the real environment MeshCollider and lightweight prop BoxColliders at runtime.
- Uses the real Arcade Machine as ARCADE_CABINET_01.
- Places ARCADE_SCREEN_01 over the real cabinet for the current test framebuffer.
- Creates a visible physical interior exit door and ARCADE_EXIT marker.
- Adds an invisible safety floor under the imported environment.
- Moves the complete textured room to the same-elevation isolated pocket before teleport.
- BUILD_AND_INSTALL.cmd copies the raw scene package automatically.
- No Unity Editor or AssetBundle is required for this test path.

Source FBX and full original textures remain in UnityAssetsToCopy for eventual proper AssetBundle production.
