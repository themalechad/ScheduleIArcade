Schedule I Arcade M2.25 - Grid ParentProperty placement crash fix

Fixes the M2.24 crash when confirming placement of the vanilla TV:
GridItem.InitializeGridItem -> NullReferenceException.

Cause:
M2.24 instantiated the proxy Grid as a detached root. Grid.Awake ran immediately,
so its cached ParentProperty was null. The ghost could detect the cloned tiles and turn
valid, but BuildManager.CreateGridItem crashed when it tried to initialize the placed item.

M2.25:
- Instantiates the Grid clone directly under the source owned Property transform.
- Lets vanilla Grid.Awake cache a valid ParentProperty.
- Verifies ParentProperty before making the arcade grid available.
- Attempts the native private _parentProperty field as a wrapper-safe fallback.
- Refuses to enable a null-property proxy instead of allowing a placement crash.
- Moves the already-initialized grid into the arcade only after validation.

Test:
1. Run BUILD_AND_INSTALL.cmd.
2. Enter the custom arcade.
3. Look for a log containing ParentProperty='...'.
4. Equip the vanilla TV.
5. Place it on an open checkerboard floor tile.
6. Placement should complete without the GridItem.InitializeGridItem NRE.
