Schedule I Arcade M2.8 - REAL FBX ASSET TEST
===========================================

WHAT CHANGED
------------
This build no longer needs to show the plain procedural cube room when the supplied arcade assets are present.
The included arcade.fbx was converted into a small runtime mesh package and the real texture maps are installed with the mod.
Unity player builds cannot import FBX directly, so the DLL reconstructs the seven real meshes at runtime.

Included real scene objects:
- Environment / room geometry
- Pinball Machine
- Arcade Machine
- Table Top
- Crane Game
- Air Hockey
- Vending Machine
- Their supplied diffuse, normal and emission textures where available

TEST
----
1. Run BUILD_AND_INSTALL.cmd.
2. Confirm the builder prints:
   Installed real arcade FBX runtime geometry/textures
3. Start Schedule I and load a save.
4. The MelonLoader log should print:
   Loaded real arcade FBX geometry/textures from runtime asset package (7 meshes).
   Schedule I Arcade runtime initialized with REAL FBX GEOMETRY + TEXTURES.
5. Go to the vanilla Northtown Arcade door and knock.
6. Choose Enter Arcade.
7. You should now be standing inside the actual textured arcade model instead of seeing the sky/procedural room.
8. Walk around and confirm the machines and room geometry are visible and collidable.
9. The interior exit is a visible physical door near the spawn point. Walk to it for [E] Exit Arcade.
10. Aim at the actual arcade cabinet for [E] Play Arcade. The test framebuffer should appear over its screen.

FALLBACK
--------
If the raw mesh package fails to load, the mod deliberately falls back to the old procedural test room and logs the exact exception.
Please send that exception if it happens.
